Автоматизированный сервис мониторинга и фиксации изменений клиентской части портала разметки CS2 VACNet (`counter-strike.net/vacnet/clips`).
Репозиторий развернут в качестве вспомогательного пайплайна для оперативного отслеживания ротации бандлов, модификаций DOM-дерева и предотвращения десинхронизации с кодовой базой расширения.
Сбор данных и аудит расхождений выполняются каждые 6 часов в среде GitHub Actions с предварительной фильтрацией сессионного шума, динамические и контекстные поля исключаются из сравнения.
При обнаружении апдейтов кодовой базы, автоматически изолирует структурный diff, актуализирует журнал изменений и публикует свежий срез в GitHub Releases.

### Навигация по репозиторию
* `snapshots/current/` — актуальный эталонный срез страницы (сырой HTML и нормализованный JSON-парсинг).
* `snapshots/outdated/` — архив предыдущих ревизий с изолированными `.diff` патчами изменений.
* `CHANGELOG.md` — хронологический реестр зафиксированных структурных модификаций.
* `tracker/` — логика парсера, движок сравнения и модуль выгрузки ассетов.
